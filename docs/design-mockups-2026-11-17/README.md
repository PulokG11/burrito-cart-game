# Design mockups (2026-11-17)

Redesign proposal for Burrito Cart, made on a Claude design canvas: https://claude.ai/artifact/3sHWB2Mx9tiJp7LJyHrrSx

- Main.dc.html: design review (current game vs inspiration, keep / fix, colour, type, principles)
- Play.dc.html: Round 1 Day 1 play screen, dragging a truck
- Results.dc.html: day results on one map (your plan vs best plan)

These are mockups only; the game code is unchanged. Numbers come from the game's engine and scenario v1. The .dc.html files render on the canvas; images there are hosted on the canvas (before-screenshots/ holds the originals).
